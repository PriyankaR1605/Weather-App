# Weather App

A simple weather application built using HTML, CSS, and JavaScript that allows users to search for any city and view its current weather information in real time.

## Overview

This application fetches live weather data using the WeatherAPI service. Users can enter a city name, and the application displays the city's current temperature, local time, and location details.

## Features

* Search weather information by city name
* Display current temperature in Celsius
* Show local date and time of the selected city
* Display city, region, and country information
* Real-time weather data using an external API
* Simple and responsive user interface

## Technologies Used

* HTML5
* JavaScript
* WeatherAPI

## How It Works

1. The user enters a city name in the search box.
2. A request is sent to the WeatherAPI service.
3. The API returns the current weather information for the selected city.
4. The application displays:

   * City Name
   * Region
   * Country
   * Local Time
   * Current Temperature (°C)
